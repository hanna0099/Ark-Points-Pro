# Ark Points Pro

Vrew SRT → 포인트 자막 + 효과음 → Premiere Pro 자동 반영 도구

## 기능

- **SRT 자동 감지**: Premiere Pro 프로젝트에서 Vrew SRT 파일 자동 검색
- **AI 포인트 자막**: Claude Sonnet 4.5 / Gemini 기반 자연스러운 한국어 요약
- **번호 시리즈 자동 묶기**: "첫 번째/두 번째/..." 발화 자동 감지 및 일괄 포함
- **효과음 자동 매칭**: 카테고리별 규칙 기반 효과음 배정
- **PP 자동 반영**: 자막 트랙 + 오디오 트랙 한 번에 적용

## 설치

테스터 분들은 `ArkPointsProSetup.exe`를 받아서 더블클릭으로 설치하세요.
자세한 사용 방법은 설치 후 함께 제공되는 README.txt 참고.

## 요구사항

- Windows 10/11
- Premiere Pro
- Node.js LTS
- Git for Windows (자동 업데이트용)
